## 🛠 Arquitectura y Tecnologías

Este sitio estático está construido priorizando el rendimiento, la personalización y la integración con flujos de trabajo de ciencia de datos reproducibles:

* **Framework:** [Hugo](https://gohugo.io/) (Generador de sitios estáticos ultrarrápido).
* **Plantilla:** [HugoBlox](https://hugoblox.com/) (Versión 2.0).
* **Estilos:** Tailwind CSS con ajustes personalizados para paletas de colores dinámicas (Modo Claro/Oscuro) usando CSS puro (`custom.css`).
* **Desarrollo R / Markdown:** Artículos, tutoriales y documentación de código procesados e integrados utilizando [Quarto](https://quarto.org/) y el ecosistema `tidyverse` / `sf` / `gstat`.
* **Entorno de Desarrollo:** [Positron](https://positron.posit.co/) / Visual Studio Code en macOS.

## 📁 Estructura del Repositorio

* `content/` - Archivos Markdown (`.md`) de las diferentes secciones del sitio (Proyectos, Publicaciones, Cursos).
* `data/authors/` - Metadatos de perfil e información del autor (`me.yaml`).
* `assets/css/` - Hojas de estilo personalizadas (`custom.css`), control de tipografías (Encode Sans, Bree Serif, Quicksand) y variables visuales.
* `static/` - Imágenes, documentos (PDFs de artículos) y otros recursos estáticos.
